# Watch Heart: development handoff

Read this first when picking the project up in a new session or from another account. It sums up the work so far, where things stand, and the rules to keep. Last written 2026-11-13, at master `b753d2a` (What's new 1.5.8, published).

**App:** Watch Heart, a diary for films, series and anime. Free Android app, one of the Heart Apps by Inigo. Expo SDK 58, React Native 0.88, Expo Router, SQLite on the phone, Supabase for accounts, sync and friends, and TMDB, TVmaze and OMDb for data.

## Rules to keep

- **Commits** as `Inigo <270059847+inigo-code@users.noreply.github.com>`. No Claude co-author trailer and no "Generated with Claude Code" line.
- **Never print API keys** (TMDB, OMDb). For a test, `eas env:pull` into a scratch file, use it, delete it. Setting secrets is Inigo's step.
- **Ask before outward actions**: pushing, releases, OTA publishes, site uploads, Play uploads.
- **Every update gets a What's new entry** with a new id, OTAs included. An update without one shows nothing.
- **Every OTA goes to both channels**, `preview` (APK phones) and `production` (Play phones).
- **Older runtimes**: since 2026-11-08 every phone is on 1.5.0 or later, so OTAs go from master only. The `ota-1.4`/`ota-1.3` branches are history.
- **JS changes go over the air; native changes need a build.** A new native module or plugin changes the runtime, so publish pending JS OTAs first.
- **EAS builds are scarce**: free plan, 15 Android builds a month, shared with Prompt Heart. November is used up; it resets 1 December. Build the APK first, test it on a phone, then build the AAB once. Check with `npx eas-cli@latest account:usage inigojo`.
- **Releases**: the GitHub release must carry `watch-heart.apk` under that exact name, or the site's download buttons break.
- **Widget files keep `"use no memo"`**: the React Compiler breaks react-native-android-widget.
- **`patches/`** holds a patch-package fix for react-native-android-widget (resize and taps), pinned to LF line endings. Keep it applying cleanly after any package update.
- **Preview server**: port 8082 belongs to Prompt Heart. Use Watch Heart's own entry in `.claude/launch.json`.
- **The look** (since 1.6.7): three faces, each with one job (`fonts` in `src/lib/theme.ts`). Instrument Sans for everything you read and tap; Bebas Neue only for the wordmark, the tab pages' big titles and big numbers; Courier Prime only on printed artefacts (Diary tickets, the entry's ticket stub, the stamp, stories and cards). Interface text is sentence case with no letter-spacing. Gold (`theme.accent`) is for the page's main action, stars and the current tab; a selected chip or segment uses `chipActive`. No glows, no page gradient, section headings via `SectionLabel`. Since 1.6.8: callouts, tips and notes are neutral cards (`theme.card`/`theme.border`, never `accentSoft` or an accent border); icons in rows sit plain in `textMuted`, with no tinted tile; buttons are solid or tonal (`theme.chip`), never dashed (dashes are for ticket perforations and empty "add" slots); sideways rows run to the screen's edges with `rail.edge` from `components/title/Rows.tsx`; the back arrow is a disc only on pages whose top is a picture (`FLOATING` in the tab stack's `_layout.tsx`), plain elsewhere, and those picture pages put `TopScrim` after their scroll view so the bar fills in as the picture scrolls away. Since 1.6.9: the tab bar and every log button use Watch Heart's own icons (`CineIcon` in `components/CineIcon.tsx`: cinema, ticket, lens, bookmark, reel, clapperboard, each with a line and a filled `on` form). They're SVGs in `assets/icons/src` (24 grid, 1.75 stroke, black) drawn to 96 × 96 PNGs by `node store/make/icons.mjs` and tinted with expo-image `tintColor`, because the build has no SVG library and pictures ship over the air. Home's week is a film strip (`WeekStrip`: sprockets, frames, today's frame lit in `accentOnDark`); a planned movie night is a ticket (`MovieNightCard`: `ticketPaper`, stub with day, date and time, `TicketTear` from `components/Diary.tsx`); `Poster` draws a hairline edge over the picture. Haptics go through `useHaptic()` in `lib/haptics.ts` (respects Settings › Haptics): `tick` in `useTracker().toggle`, `step` in `StarInput`. Since 1.7.0: logging something new shows its own Diary ticket with a LOGGED stamp (`LoggedStamp`, skipped with reduced motion, `stamp` haptic); empty pages are drawn with `EmptyScene` (a blank ticket for the Diary and lists, an empty strip for the Watchlist and Recap) and one accent button; Recap has `RecapReel` (each title once, in order, busiest day lit via `busiestDay` in `lib/stats.ts`); the Up next widget's rows are tickets in Instrument Sans (fonts in the widget plugin in `app.json`; a missing font falls back on older builds), and its preview is drawn by `node store/make/widget/draw.mjs`. Text buttons and chips use `minHeight`, never a fixed `height`, so larger text grows them. Since the 1.7.0 build: no “·” separators and no coloured kind dots anywhere on screen. Lists use commas (`kindSummary` reads “a, b and c”), a count is a separate lighter number (`Segments` options take `count`), printed ticket fields are spaced apart (a row with a gap, or three spaces), and dates in sentences go through `onDay` in `components/DaySheet.tsx`. Episode progress is stored as `S1 Ep 3–5` (`S1 Ep 9–10; S2 Ep 1` across seasons); older notes written with dots are shown through `plainProgress` in `lib/tracking.ts`. A page that loads details shows placeholders the size of what's coming, never a jump: `peek()` in `api/cache.ts` gives a fresh cached answer on the first frame, `useAbout` returns `loading` only when nothing is known, `Hero` takes `pending` (bars where the year and credit go), and the title page fades its body in once.
- **No technical text on screen.** Users never see exception text, status codes, SQL file names or set-up notes. Show errors through `shownError(e, fallback)` in `src/lib/errors.ts`, and write every thrown message as plain words for people.
- Lint, typecheck and tests (`npx expo lint`, `npx tsc --noEmit`, `node --import ./tests/hooks.mjs --test "tests/*.test.mts"`) before calling anything done. The tests run the plain logic files in `src/lib` with Node's own runner, no packages. There's no `npm test` script on purpose: the runtime version is a fingerprint, and `package.json` scripts count towards it.

## Switching accounts

- **Terminal**: Windows PowerShell blocks `npx` (`npx.ps1 cannot be loaded`). Use `npx.cmd eas-cli@latest …` there, or run it from Claude.
- **Claude account**: everything above, the memory notes and `heart-apps.md` are local files, so any account on this PC sees them. Chats from another account don't carry over; this file does.
- **Expo account**: builds, updates and env variables belong to `inigojo`. Check with `npx eas-cli@latest whoami`; switch with `npx eas-cli@latest login`.
- **GitHub**: `gh auth status`. Pushes go to `inigo-code`.
- Keep master committed and pushed before switching, and update this file when the release state changes.
